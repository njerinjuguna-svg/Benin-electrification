## Overview

Benin has a national electrification rate of approximately 45%, with over **3.9 million people** living without access to electricity — concentrated in rural and peri-urban settlements far from the existing medium-voltage (MV) grid.

This analysis implements a **least-cost electrification model** that:

1. Estimates electricity demand for each unelectrified settlement over a **15-year planning horizon**
2. Calculates the Levelised Cost of Energy (**LCOE**) for three technology options per settlement
3. Assigns the **least-cost technology** — with a productive-use upgrade rule
4. Scores and ranks settlements for **investment prioritisation**
5. Tests **four cost scenarios** to assess recommendation robustness

The model is enriched with **Google Earth Engine (GEE) satellite data** — solar radiation, land cover, terrain slope, vegetation index, rainfall, and nighttime lights — extracted for every unelectrified settlement, making this more spatially precise than standard national-average approaches.

| Metric | Value |

| Total Benin population modelled | ~10.5 million |
| Unelectrified population (target) | ~3.9 million (37%) |

| Households to electrify | ~750,000 |

**Technology recommendation split:**

| Technology | Settlements | Population |
|-----------|-------------|------------|
| Solar Home System (SHS) | Majority | Smallest/most remote |
| Solar Mini-Grid | Significant share | Mid-size with productive use |
| Grid Extension | Minority | Close to existing MV lines |

**Key insight — The Energy Poverty Trap:**  
The poorest settlements (W1, RWI < −0.6) are on average **7–10 km further** from the existing grid than the wealthiest unelectrified settlements. Grid extension will never reach those who need electricity most — off-grid solar is not a compromise; it is the primary pathway.

## Methodology

### Demand Estimation

Demand is estimated using the **Multi-Tier Framework (MTF)** — the international standard for rural energy access, developed by the World Bank's ESMAP programme.

**Step 1 — MTF Tier Assignment**

Each settlement is assigned a demand tier (1–4) based on multiple signals:

| Tier | kWh/HH/year | Criteria |
|------|------------|---------|
| 1 | 22 | Population < 100 — remote hamlet |
| 2 | 73 | Population 100–299 — small village |
| 3 | 365 | Pop ≥ 300, OR health/education facility, OR active cropland (NDVI > 0.3), OR wealth ≥ W4 |
| 4 | 1,250 | Pop > 3,000, OR built-up land + pop > 1,500, OR wealthy + pop > 2,000 |

**Step 2 — Demand Formula**

```
Total Demand (kWh/yr) = Residential + Institutional + Productive

Residential  = Households × (MTF_kWh × RWI_Factor × Rainfall_Factor) × Electrification_Rate
Institutional = (Health_facilities × 500) + (Education_facilities × 300)
Productive   = Residential × Productive_Uplift[land_cover]
```

**Key modifiers from satellite data:**
- `RWI_Factor`: Wealth multiplier (0.80 for W1 → 1.20 for W5) — richer communities use more electricity
- `Rainfall_Factor`: Dry north (+15% for < 900 mm), wet south (−5% for > 1,200 mm) — water pumping/cooling demand
- `Productive_Uplift`: Cropland (+25%), Built-up (+30%), Grassland (+10%) — from ESA WorldCover + NDVI

**Step 3 — 15-Year Projection**

```
Demand(year t) = Total_Demand_Year1 × (1 + 0.03)^(t−1)
```

3% annual growth reflects World Bank rural income growth projections for Sub-Saharan Africa.

---

### Technology Options & Cost Model

Three technologies are compared for every settlement using **Levelised Cost of Energy (LCOE)**:

```
LCOE = (CAPEX + OPEX × NPV_factor) / (Annual_Demand × NPV_factor)

NPV_factor = Σ [1/(1+r)^t] for t = 1 to lifetime
```

Discount rate: **10%** (World Bank standard for Sub-Saharan Africa public investment)

#### Technology Cost Parameters

| Parameter | Grid Extension | Solar Mini-Grid | Solar Home System |
|-----------|:-------------:|:---------------:|:-----------------:|
| CAPEX per connection | $500 | $900 | $200–$400 |
| CAPEX per km MV line | $15,000 | — | — |
| Fixed CAPEX | — | $15,000 | — |
| OPEX rate | 2%/yr | 5%/yr | 3%/yr |
| Lifetime | 30 years | 20 years | 10 years |
| SHS Tier 1–2 CAPEX | — | — | $200/HH |
| SHS Tier 3+ CAPEX | — | — | $400/HH |

**Sources:** ABERME Benin grid data, ENGIE West Africa operational pricing, IRENA (2019) Sub-Saharan Africa benchmarks

#### GEE-Driven CAPEX Adjustments

Unlike standard OnSSET (which uses national solar averages), this model applies **per-settlement satellite adjustments**:

```python
# Better solar → more energy per panel → lower unit cost (±15%)
solar_adj = max(0.85, min(1.15, 1 - 0.05 × (GHI - 5.49) / 5.49))

# Steeper terrain → higher installation cost
slope_adj = 1.00 if slope ≤ 5°
           1.10 if slope 5–10°
           1.20 if slope > 10°
```

### Least-Cost Decision Logic

Technology assignment follows a three-step process:

```
Step 1: Economic minimum
  → Calculate LCOE for all applicable technologies
  → Mini-grid excluded if population < 250 (minimum viability threshold)
  → Select technology with lowest LCOE

Step 2: Productive use upgrade
  → If SHS selected AND population ≥ 250 AND (anchor load OR active cropland):
      → Upgrade to Mini-Grid
      → Reason: AC power required for motors, milling, refrigeration

Step 3: Financial viability flagging
  → Flag settlements needing subsidies based on wealth tier × technology
  → W1 + any technology → subsidy required
  → W2 + Grid Extension → connection subsidy needed
```

This logic is an intentional extension of pure LCOE minimisation, reflecting ABERME's productive use electrification policy and real-world operational constraints (SHS cannot supply AC-powered productive loads).

---

### Investment Prioritisation

Settlements are ranked using a **multi-criteria priority score (0–100)**:

| Criterion | Max Points | Method |
|-----------|:---------:|--------|
| Population impact | 25 | Linear scale: `min(population / 5,000, 1) × 25` |
| Health facility present | 12 | Binary |
| Education facility present | 8 | Binary |
| Productive use (land cover + NDVI) | 20 | Cropland=20, Built-up=18, +2 NDVI bonus if active |
| Road access | 15 | Binary if road access; decay by distance otherwise |
| Financial sustainability (RWI) | 10 | Normalised RWI × 10 |
| Solar resource quality | 5 | `min(GHI / 6.5, 1) × 5` |
| Rainfall urgency (water stress) | 5 | Higher score for drier areas |

This score enables planners to identify settlements that maximise **population impact**, are **technically feasible** to implement, have **productive use potential**, and have **communities able to sustain the system**.

### Sensitivity Analysis

Four cost scenarios were tested to assess how robust technology recommendations are to cost changes:

| Scenario | Mini-Grid Cost | Grid Extension Cost | Rationale |
|----------|:--------------:|:-------------------:|-----------|
| Baseline | ×1.0 | ×1.0 | Current market conditions |
| Mini-grid −20% | ×0.8 | ×1.0 | Conservative near-term solar cost decline |
| Mini-grid −40% | ×0.6 | ×1.0 | IRENA 2030 solar cost projection |
| Grid extension +30% | ×1.0 | ×1.3 | Supply chain disruption / rural inflation |

**Key finding:** If mini-grid costs fall 40% (consistent with IRENA's 2030 solar projection), a significant number of SHS-assigned settlements switch to mini-grids — the "tipping point" for mini-grid market development.

## Limitations & Future Work

### Current Limitations

| Limitation | Impact | Future improvement |
|-----------|--------|-------------------|
| Nighttime light proxy for electrification status | May misclassify some partially-electrified settlements | Use ABERME official electrification database |
| No grid routing algorithm | Grid extension distance uses straight-line to nearest MV line, not actual road/easement routing | Implement Dijkstra's algorithm on road network |
| Single household size (5.2) for all settlements | Does not capture urban/rural household size variation | Use settlement-specific census data |
| No population growth modelling | Demand projection uses fixed 2020 population | Add UN population growth scenarios |
| Mini-grid sizing not optimised | Fixed $15,000 base cost regardless of settlement demand profile | Size mini-grid to load curve; apply capacity-cost scaling |
| Demand growth rate not varied in scenarios | Only cost scenarios tested | Add demand growth sensitivity (1%, 3%, 5%) |
| Discount rate fixed at 10% | Does not capture financing risk variation | Test 8% (concessional) vs. 12% (commercial) |
| No grid densification option | Peri-urban settlements with nearby low-voltage lines not modelled | Add LV densification as fourth technology |

### Suggested Next Steps

1. **Validate with ABERME data** — cross-check technology assignments against existing rural electrification programmes
2. **Add grid routing** — use OpenStreetMap road network for realistic MV extension cost estimation
3. **Incorporate load profiles** — replace annual kWh with hourly demand curves for accurate mini-grid sizing
4. **Monte Carlo uncertainty** — run full probabilistic sensitivity across all cost and demand parameters
5. **Cluster analysis** — identify mini-grid clusters (groups of settlements that could share infrastructure)
